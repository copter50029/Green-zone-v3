# คู่มือฟังก์ชัน Nike

เริ่มที่ [README](../../README.md) และ [คู่มือรับงาน backend](../BACKEND-HANDOFF-th.md) ซึ่งเป็นคำแนะนำปัจจุบัน Scope เหลือ detect green zone, heatmap, noise/residential filtering และ park verification ไม่มีการสร้าง UI/HTML

ใช้ run_all() เมื่อต้องการอ่านค่าตั้งครบทั้งหมดจาก data/scenes.json ใช้ find_parks_in_image() เมื่อต้องการตรวจเฉพาะหมุดทะเบียนใน TIFF โดยไม่รันการตรวจพืชใหม่
